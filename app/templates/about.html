Machine Learning

Three Specialist Models

PrediQt is built on three independent Random Forest classifiers, each trained on a dedicated real-world dataset. The Credit Card model uses 1.85 million Sparkov transactions with merchant location, customer demographics and geographic distance signals. The Online Payment model uses 590,000 IEEE-CIS e-commerce transactions with card type, email domain and billing address verification. The Mobile Transfer model uses PaySim mobile money data with transfer type and balance change analysis. Together they cover the full spectrum of modern financial fraud.

Intelligence

Smart Auto-Routing System

The routing engine automatically determines which specialist model should analyse each transaction based on the transaction type selected by the user. Card purchases, ATM withdrawals, contactless payments and grocery transactions are routed to the Credit Card model. E-commerce orders, digital payments and subscriptions go to the Online Payment model. Bank transfers, mobile payments and cash withdrawals are handled by the Mobile Transfer model. The user never needs to choose a model manually. The system decides silently and instantly in the background.

Platform

Full-Stack Fraud Platform

PrediQt is a complete fraud detection platform built with Python, Flask and SQLite. Users can check individual transactions through the universal prediction form, upload batch CSV files containing thousands of transactions for bulk processing, and monitor a live real-time transaction feed on the dashboard. Every prediction is stored with its risk level, fraud probability, transaction type and model used. Admin users have access to platform-wide statistics, full user management and audit capabilities. The platform runs entirely locally with no cloud dependency.
